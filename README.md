# AKAKOS Solar Calculator — web app (GitHub Pages)

Single-file bilingual (EN/AR) solar PV + battery sizing & offer tool by AKAKOS Renewable Energies, Tripoli, Libya.

**Live app:** https://reyad1000.github.io/akakos-solar-calculator/

## How to publish / update (GitHub Pages)
1. Create a **public** repository named `akakos-solar-calculator` (Settings → Pages → Build from branch **main**, folder **/ (root)**).
2. Upload ALL files in this folder to the repository root: `index.html`, `manifest.webmanifest`,
   `icon-192.png`, `icon-512.png`, `icon-512-maskable.png`, `apple-touch-icon.png`, `.nojekyll`, `README.md`.
3. Wait ~1 minute → the link above is live. On iPhone: open in Safari → Share → **Add to Home Screen**
   (installs like an app, full screen). On Android: Chrome → ⋮ → **Add to Home screen**.
4. To release a new version: replace `index.html` only (keep the same name) → clients get it on next open.

Build: V7.1 WEB (PDF libraries embedded — PDF/WhatsApp/Email offers work with no external downloads).
